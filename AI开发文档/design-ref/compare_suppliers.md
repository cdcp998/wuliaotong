# 供应商管理（设计页 15） —— 设计基准 vs 实机截图 视觉比对

【符合】

1. **页头**：区域内的主标题「供应商管理」、副标题「供应商档案：编码自动生成、简称归一（自动合并重复供应商）、采购价关联」的文字内容、位置及字体样式与图1一致。
2. **页头右侧按钮**：「Excel 导入」「导出」（白底描边）与「新增供应商」（蓝色主按钮）的按钮样式、图标和排列位置基本一致。
3. **筛选条**：搜索框（宽度约300）、状态下拉框（宽度约160）的尺寸、位置、占位符文本「供应商名称 / 编码 / 联系人」、「全部状态」均与图1一致。
4. **表格卡**：卡片圆角、阴影、表头列名（供应商、编码、联系人、电话、最近供货、状态、操作）的顺序与位置一致。

【不符合】

1. **筛选条右侧统计文字**：图1显示为「共 42 家 · 合作中 38」，实际图2显示为「共 0 家 · 启用 0」；文案中「合作中」被替换为「启用」，且数据量不一致。
2. **表格卡数据为空**：图1表格内包含5行供应商数据，实际图2表格内为空，显示「暂无供应商」。这导致图1中供应商列下的灰色小字（简称/统一社会信用代码）、状态列下的绿色（合作中）/橙色（待合并）/灰色（已停用）胶囊、操作列下的「编辑/停用」按钮均缺失。
3. **缺失「待合并」胶囊**：图1的「老城五金电器（疑似重复：城南五金）」行，在供应商名称下方有橙色「待合并」胶囊；实际图2因无数据不存在该元素。
4. **表格行布局无法验证**：由于图2无数据，没有渲染表格行，无法查看行的垂直间距、单元格内边距、状态胶囊的具体颜色与字体等细节是否与图1完全吻合。

【建议】

1. **【优先级：高】填充表格数据**：实际实现为空态。需接入数据或使用 mock 数据还原图1中的至少5行供应商记录，确保表格布局、列宽、单元格样式能够被正确验证。
2. **【优先级：中】修正右侧统计文案**：将筛选条右侧文字改为「共 N 家 · 合作中 N」，或若产品已将「合作中」改为「启用」，请同步更新设计基准图。
3. **【优先级：中】实现「待合并」胶囊**：在表格供应商列中增加「待合并」橙色胶囊的样式（背景色、文字颜色、圆角），并确保在存在疑似重复供应商时显示于名称下方。
4. **【优先级：低】统一空态样式**：若数据为空是真实场景，建议参照图1的卡片风格设计一个美观的空态占位（如添加图标或说明文字），而非仅显示「暂无供应商」，以保持整体视觉一致性。
