### 2.2 圆角 / 阴影 / 字体
- 圆角：卡片 `16px`、弹窗/底栏 `20px`、控件/输入 `10-12px`、小图 `8-12px`、胶囊 `999px`、图标按钮 `10-12px`

- 字体：`PingFang SC`（无衬线）；标题 20-22px/700；区块 13-14px/700；正文 12-12.5px；注释 10.5-11px
- 玻璃底：`rgba(255,255,255,.92~.96)` + `backdrop-filter: blur(8-10px)`（顶栏/底部工具条）

- **统计卡**：数值 20-24px/700 + 标签 12.5px
- **表格**：表头 `#F6F8FE` 圆角 10，行白底描边分隔，操作列品牌色文字按钮

- **底部工具条**（手机/平板）：`rgba(255,255,255,.94)` + blur + 上描边 + safe-area 内边距

## 5. 必须保留的业务语义（画布已表达，代码实现时对齐）
1. 库存不足领用：提交先负数出库 + 24h 回补提示；驳回/取消自动回补
2. 盘点盈亏过账 → 自动生成其他出入库并通知仓管员；空库位需“已盘”
3. 调拨：同仓即时、跨仓审核；审核通过自动扣/增并回写库位；逐条锁库存防超调
4. 删除分类→删除审核流（管理者+）；材料删除=停用
5. 设备维修完成 → 自动回退设备“在用”；维修中设备挂起领用
6. 模块依赖链（device 依赖 task，停用 task 后启用 device 报 4002）
7. 日志只增不改不删；备份保留最近 14 份滚动；关键操作（模块启停/地图源/删除审核/短信）可高亮
8. OCR：识别仅预填，人工校正；未匹配材料现场新建
9. 知识推荐在任务记录抽屉；AI 建议不自动执行（人审）；LLM 槽位 OpenAI 兼容、失败可重放
10. 手机端拍照/GPS 带水印留痕；领用/任务流程“提交→审计→完成拍照”

## 6. 新会话实施建议顺序
1. 复制本文件到新会话 → 打开 `.op`（或按本文件描述直接实现）
2. 设计系统：`main.tsx` ConfigProvider tokens + `global.css`（.wlt-glass/.wlt-pill/.wlt-fill 等）+ 双端 CSS 变量
3. 桌面端骨架（AppLayout 100dvh + 侧栏/顶栏/内容滚动）→ 逐模块实现（可依 3.1 表顺序，每屏一小步提交）
4. 响应式：desktop `mobile.css`（≤768 抽屉侧栏/表格横滚/单列）+ 769-1199 留白；mobile `widescreen.css`（600/720 居中 + 弹窗限宽）
5. 手机端逐屏（依 3.2 表，底部工具条统一组件 TabLayout）
6. 每步 `tsc --noEmit` + `npm run build`（wlt-desktop / wlt-mobile）后提交；提交格式 `类型(范围): 描述`
