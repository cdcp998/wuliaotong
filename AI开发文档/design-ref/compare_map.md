# 地图工作台（设计页 46） —— 设计基准 vs 实机截图 视觉比对

【符合】

- 左上角存在图源 pill（“Esri 影像” + 下拉箭头），位置基本正确。
- 右上角工具栏五个图标（位置/测距/图层/刷新/标记）均带小文字，图标数量和排列顺序符合要求。
- 左下角存在“故障导航” pill。
- 右下角存在缩放 +/- 控件和指北图标。

【不符合】

1. **页头**：图2 顶部存在完整系统页头（Logo、“物料通”、“地图工作台”、搜索框、通知铃铛、管理员信息），而设计基准要求“无页头”（检查点1）。
2. **左侧面板**：图2 左侧存在完整导航侧栏（工作台、基础资料、线缆与地图等），而设计基准要求“无左侧面板”（检查点1）。
3. **地图铺满**：地图未铺满整个视口，被顶部页头和左侧侧栏挤压在右侧内容区，存在大面积非地图 UI，违反“无白边空边/地图铺满”要求（检查点5）。
4. **图层下拉**：右上角“图层”图标下方未显示“叠加图层”下拉面板，设计基准中该面板应挂在工具栏下方（检查点3），实际截图缺失。
5. **左下“图例”**：设计基准要求“故障导航 pill + 图例 pill”两个独立元素；图2 中图例只是故障导航 pill 下方的一行小图标，未形成独立 pill，且与故障导航的关系为上下排列而非并列/符合基准布局（检查点4）。
6. **多余元素**：右下角出现“Leaflet | 卫星影像”版权/来源标注，设计基准中无此元素。

【建议】

1. **最高优先级：移除页头和左侧面板**，让地图全屏铺满、无内边距。若产品必须保留侧栏和页头，则需要重新确认设计基准是否允许“应用壳”，但按当前检查点应删掉。
2. **补齐“图层”下拉面板**：在右上“图层”图标正下方挂出“叠加图层”面板，按设计基准展示层列表与复选框（如线缆层/故障层/设备层/标记点层）。
3. **重排左下角图例**：将线路/故障/设备/标记图例做成独立 pill，与“故障导航” pill 的标准布局对齐（具体并列方式以设计基准图为准）。
4. **移除右下角 Leaflet 标注**：隐藏或删除该版权元素，保持界面干净。
5. **核对左上图源文案**：若设计基准明确规定为“高德 · 卫星”等指定文案，需将“Esri 影像”替换为基准文案。
